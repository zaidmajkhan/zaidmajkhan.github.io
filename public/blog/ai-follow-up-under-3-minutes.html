Getting AI follow-up under 3 minutes

“AI follow-up” sounds like a product. In practice it’s a sequence of hand-offs: ingest → qualify → draft → send → log → escalate. If any step waits on a human inbox, you’re back to four-hour response times with nicer wording.

Design the queue first

Before picking models or SMS vendors, map:

  • Where leads enter (forms, missed calls, aggregators)
  • What “ready to respond” means for each type
  • Who owns the conversation after the first message
  • What never gets automated (price negotiation, credit nuance)

That map is the same muscle as pharmacy peak-hour sequencing — constraint first, tooling second.

A minimal reliable loop

  1. Webhook or poll creates a lead event within seconds
  2. Template + light model fill personalizes the first touch
  3. Message sends via email or SMS with idempotent logging
  4. Human is notified only when a reply arrives or confidence is low

I’m coding this pattern in Python with the Claude API and Gmail in a public repo — lead-followup-agent. Edge cases (duplicates, bad phone numbers, office hours) still need work.

Measure what matters

Track first-response time, reply rate, and booked next steps — not “messages sent.” If response time is under three minutes but nobody books, the copy or offer is wrong, not the model.
