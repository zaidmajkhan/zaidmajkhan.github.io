# zaidmajkhan.github.io

Personal portfolio for **Zaid Khan** — ISEN @ Texas A&M.

**Live:** https://zaidmajkhan.github.io

## Stack

- React 19 + Vite 6
- Tailwind CSS v4
- Figtree + Newsreader typography
- Forest / cream visual system
- GitHub Actions → Pages (`dist/`)

## Develop

```bash
npm install
npm run dev
npm run build
```

## Config

Edit [`src/config/siteConfig.js`](src/config/siteConfig.js) for resume/social/form/todo app URLs.
